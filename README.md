## AI Image Generator 🎨

•An AI Image Generator built with Python, Streamlit, and Stable Diffusion 2.1. 
•Enter a text prompt and generate AI-generated images.

## Features

•Enter a text prompt
•Generate AI images
•Powered by Stable Diffusion
•Simple Streamlit interface

## Technologies

•Python
•Streamlit
•PyTorch
•Hugging Face Diffusers
•Transformers
•Stable Diffusion

## Project Structure

AI-Image-Generator/ ├── imagegenerator.py ├── requirements.txt └── README.md

## Run the App

•streamlit run imagegenerator.py

## Usage

•Open the Streamlit application.
•Enter an image description.
•Click Generate Image.
•Wait for the AI-generated image.

Example Prompt: "A cute cat sitting in a beautiful garden"

## Model

Uses the Hugging Face model:

"stabilityai/stable-diffusion-2-1-base"
